# WORKNOTE v30.2 — 休日AIモード + 日報閲覧セルナビ更新

## 1. 休日モード
シフトが OFF / 希望休 / 休日 の日は日報AIを自動で「休日モード」に切り替えます。

休日では以下を評価しません:
- 店舗実績の不足
- 個人販売の未達
- スタッフへの介入不足
- 店舗全体を見る力の不足
- 報連相不足
- セルナビ店舗数字

代わりに、日報に実際に書かれた:
- 訓練
- 学習
- 振り返り
- 課題整理
- 次回出勤の準備
- 自主的に考えたこと
を中心にAIメンターが評価します。

証拠のない管理職8領域は低評価にせず「？」扱い。
休日に日報を書かなかった日は週次分析でもマイナス評価しません。

## 2. 日報閲覧画面でもセルナビ確認
出勤日の日報を普通に開いた閲覧画面でも「セルナビ店舗数字」を常時表示。
小さな「更新」ボタンで最新状態へ更新できます。
保存済みスナップショットがなくても、同日の最新セルナビ共有データがあれば表示します。

## 3. 日報編集画面
出勤日:
- セルナビ同期済み + 小型更新ボタン

休日:
- 「今日は休日 / 店舗数字はAI評価対象外」と薄く表示
- セルナビ再同期ボタンは表示しません
