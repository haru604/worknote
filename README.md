# WORKNOTE v21

## v21 更新内容
- ホーム画面に縦型の「イベント」一覧を追加
- 今日以降に関係するイベントを最大6件まで時系列表示
- 実施中の施策・割引は「実施中」と表示
- 今後のイベントは「明日」「○日後」で開始時期を表示
- 種類（施策・割引・端末発売・予約）と期間をコンパクト表示
- イベントをタップすると該当日のカレンダーへ移動
- 「カレンダーを見る」から一覧確認も可能
- v20のAIチャット→期間イベント自動登録機能はそのまま維持

## 運用イメージ
AIチャットへ「8/10〜8/31 Pixel予約キャンペーンをカレンダーに入れて」のように依頼すると登録され、
その後はホーム画面だけで直近の施策・発売・予約・割引時期を確認できます。
