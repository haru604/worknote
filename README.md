# WORKNOTE v9.1.0

## 今回の更新
- メモ追加・編集画面をフルスクリーン化
- 大きな本文入力欄と上部固定の「閉じる／保存」を追加
- 通知許可だけで終わっていた旧実装を修正
- 設定 → 通知に「テスト通知を送る」を追加
- 自動タスク編集に「端末へ通知」スイッチを追加
- 出勤時・昼・退勤前の未完了タスク通知を追加
- 通知タップ時にWORKNOTEを開く処理を追加

## 通知の使い方
1. 設定 → 通知 → 通知を許可する
2. 同じ画面で「テスト通知を送る」を押して端末に届くか確認
3. 設定 → 自動タスク → 対象タスクを編集
4. 「端末へ通知」をONにして保存

※ 通知時刻の目安
- 出勤時：登録シフトの開始時刻
- 昼：13:00
- 退勤前：登録シフトの終了30分前
- 終日：10:00

※ ブラウザだけで作るPWAのため、Androidがアプリを完全停止・省電力制限した場合は、時刻どおりのバックグラウンド通知が保証されない場合があります。テスト通知で端末側の通知許可を確認してください。


## v9.1.0 変更点

## v11.0.0 変更点
