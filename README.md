# WORKNOTE v29 — AI副店長メンター

## 日報AIを「継続育成メンター」へ刷新
数字だけではなく、日報に書いた1日の流れ・行動・判断・発言・スタッフとの関わり・失敗・自己訓練まで分析します。

### 毎回の分析
- 前回の約束・課題を実行したか
- 今日の目標と実績
- 販売スタッフとしての評価
- 副店長としての評価
- 1日の時間配分・優先順位
- 数字管理・店舗全体把握
- スタッフ育成・店舗管理
- 発言・報連相・コミュニケーション
- 良かった判断・改善点
- 副店長8領域を ◎ / ○ / △ / × / ？ で評価
- 次回の具体行動と最優先1つ
- 長めのメンターコメント

## 課題診断
できなかった原因を以下から分類:
知識不足 / 技術不足 / 経験不足 / 習慣不足 / 優先順位ミス / 判断ミス /
コミュニケーション不足 / 自信不足 / 仕組み不足

原因を断定できない場合は仮説として扱います。

## 実用的な訓練
苦手に対して:
- 目的
- やり方
- 時間 / 回数
- 測定方法
- 次の段階
までGeminiが具体化します。

例: 縦書き音読なら「30分読む」で終わらず、視線移動・初見読み・詰まり回数などを改善指標として扱えます。

訓練は日報画面から「毎日」の既存自動タスクへ追加できます。

## 継続追跡
- 前回AIの最優先・行動・訓練を次の日報で確認
- 同じ課題の再発回数を保存
- 再発が続けば「意識」ではなく訓練・仕組み化へ切替
- 改善を継続した課題は「卒業」判定し、次の難度へ進む

## 週次メンター総括
AI画面に「直近7日の育成総括」を追加。
手動実行なので、画面を開くだけではGemini APIを消費しません。
- 伸びたこと
- 繰り返す課題
- 販売実績
- 副店長・管理職としての状態
- 卒業できた課題
- 来週の重点
を分析します。

## 既存機能

スタッフ分析、複数スタッフメモ、リッチメモ、Android戻る等を維持しています。
