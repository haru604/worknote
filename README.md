# WORKNOTE v29.1 — AIメンター総点検修正版

## Gemini混雑エラー
- high demand / 503 / 429 等を日本語化。
- 一時的な混雑時は1回だけ自動再試行。
- AI画面に生の英語エラーを出さない。
- 日報・週次分析では失敗後もその場で再試行可能。

## 日報AI再分析
- フィードバック上部にも「この日報をもう一度AI分析」を追加。
- 下部の再分析ボタンと同じ処理へ統一。
- 分析失敗時も以前のフィードバックを消さない。
- エラーを日報内に表示し「もう一度再分析する」から再試行。
- 成功後はエラー状態を自動クリア。

## 直近7日の育成総括
販売実績中心の設計を撤廃。
主役を「副店長・管理職としての成長」に変更。

分析内容:
- 副店長としてできるようになったこと
- 管理職8領域
- 1日の使い方・優先順位
- スタッフ育成・店舗全体を見る力
- 判断・報連相・発言
- 繰り返している課題
- 日々の訓練が能力改善につながったか
- 卒業できた課題
- 来週鍛える管理職能力 1〜2個
- 実践方法と達成判定

販売件数や売上は週次総括の独立テーマにしません。
個人販売力は、副店長自身が店舗の基準になれているかを見る補助要素としてのみ扱います。
