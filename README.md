# WORKNOTE v24

## 今日の重点
- ホームの「今日の重点」は独立入力を廃止
- 当日の日報に入力した「今日の目標」をそのまま表示
- 日報側で目標を変更するとホームも自動反映
- 目標未入力時は「今日の目標を入力」を表示
- ホームから当日の日報編集へ直接移動可能

## 自分自身（ヒガ）の分析
- AI → スタッフ別の一番上に「ヒガ（自分）」を固定表示
- 日報の各文章から、行頭にスタッフ名がない行だけを本人記録として蓄積
- スタッフについて書いた行は本人分析から除外
- ヒガ詳細画面では、強み / 課題 / 最近の変化 / 次に改善すること / 記録履歴を表示
- 「副店長としての自己成長」を追加
- Gemini分析では 判断 / 数字管理 / スタッフ育成 / 商談 / 報連相 / 行動改善 の6観点で評価
- 自己成長分析は「Geminiで自己成長を分析」を押した時だけ実行
