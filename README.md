# WORKNOTE v17

## 更新内容
- ホームの挨拶を「挨拶」「名前」の2行固定表示へ変更
- ホーム画面のAI副店長補佐カードを撤去し、ホームを今日の仕事に集中する構成へ整理
- AI画面のスタッフ一覧を廃止し、「スタッフ別」入口カードから専用画面へ移動する構成へ変更
- スタッフ一覧 → スタッフ詳細の2階層画面を追加
- スタッフ詳細に育成ステータス、強み、課題、最近の変化、次回の関わり方を表示
- 日報・MTG・スタッフメモからスタッフ別の履歴を自動集約
- Gemini直接接続時はスタッフ詳細から個別分析を任意更新可能。失敗時も端末内分析を継続
- PWAキャッシュを v17.0 に更新

## 注意
- スタッフ分析は保存された業務上の記録だけを対象にします。個人情報・お客様情報は入力しないでください。
- Gemini APIキーは端末内保存で、バックアップやGitHubには含みません。
