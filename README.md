# WORKNOTE v28

## AIからの気づき
- ホームの気づきカードをタップ可能に変更。
- 月目標ペース → 該当項目の進捗詳細。
- スタッフ育成 → 該当スタッフ詳細。
- MTG未反映 → メモ画面。
- 期限超過 → 今日のタスク位置へ。

## 実績進捗詳細
月目標がある各項目で以下を表示:
- 月目標
- 現在実績
- 残り
- 残り出勤日
- 1出勤あたり必要件数 / 台数 / 金額
- 達成率
- 直近実績

実績管理の各項目カードからも同じ詳細を開けます。
計算は端末内で行いGemini APIは使用しません。

## 休日と自動タスク
既存の「対象」設定をそのまま厳密に使用:
- 毎日 → 休日を含め毎日
- 毎出勤日 → 出勤日のみ
- 早番のみ → 早番の日のみ
- 遅番のみ → 遅番の日のみ
- フルのみ → フルの日のみ

休日でもその日の予定、通常タスク、「毎日」の自動タスクをホームに表示します。
新しい対象条件は追加していません。
