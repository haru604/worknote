# WORKNOTE v31.2 — CARD SCORE連携・マネ活日報対応

## 今回の主な更新
- 日報の実績入力へ「機種変更 内マネ活」「セルアップ 内マネ活」を追加
- 既存の「クレカ」「内GOLD」「じぶん銀行」「機種変更」「セルアップ」と合わせてCARD SCOREへ自動連携
- シルバー枚数は「クレカ合計 − GOLD」で自動算出
- 日報保存・編集・削除後も、日付単位の最新値で `worknote_cardscore_daily_v1` を再構築
- CARD SCORE側の再同期でも二重加算されない上書き連携仕様
- 機種変更/セルアップのマネ活件数が対象件数を超える入力、GOLDがクレカ合計を超える入力を保存時に防止

- メモを押すとフルスクリーン閲覧
- 日報 / MTGは既存機能維持

## ROLEUP双方向連携
### WORKNOTE → ROLEUP
- AI画面に「ROLEUP訓練」カードを追加
- AIに現在の課題から次のROLEUP課題を選定させる
- 日報フィードバックで実践練習が必要な場合だけ「推奨ROLEUP」を表示
- 「ROLEUPで練習」を押すと課題・重点・商材・難易度をROLEUPへ共有

### ROLEUP → WORKNOTE
- ROLEUPのロープレ結果をWORKNOTEが自動読込
- 総合点 / 6項目 / 改善点 / アドバイス / 会話全文 / 課題IDを参照
- ROLEUP結果を翌日以降の日報AIへ渡す
- AI画面からROLEUP結果をGeminiに再評価させ、次の判断を
  - 再練習
  - 難易度アップ
  - 実務確認
  - 卒業
  に分岐

## 月間成長レポート
AI画面に「月間成長レポート」を追加。
対象月に入力した以下を横断してGeminiが報告書を生成:
- 日報
- 通常メモ / 業務連絡 / スタッフメモ
- MTG
- 日次AIフィードバック
- 週次AIメンター
- 継続記憶 / 店長指示
- 休日の学習 / 訓練
- ROLEUP履歴 / 会話 / 評価

販売実績報告ではなく、副店長としての成長を主題にします。
生成は手動で、保存後は過去月も閲覧できます。
