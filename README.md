# WORKNOTE v27.1 — v27 総点検・バグ修正版

## 修正1：ホーム「期限超過タスク」の誤判定
- 過去の自動・繰り返しタスクを期限超過として数えないよう修正。
- 期限超過判定は、未完了かつ過去日付の「手動 / スタッフ育成 / MTG等から作られた実タスク」のみ。
- 過去の自動タスク自体はデータ削除せず、履歴として保持。

## 修正2：AI → 実績管理が押せない
原因:
- performanceMonthCursor が Date オブジェクトなのに YYYY-MM 文字列として処理されていた。
- formatPerformanceValue / performanceCompactSummary が未定義だった。

修正:
- 月カーソルを YYYY-MM に統一。
- 月移動・日別画面・戻る履歴も同じ月を保持。
- 不足していた実績表示関数を追加。
- 今月の目標13項目を入力・保存できる状態へ修復。
- +1Collection と有償サポートは円表示。

## 修正3：日報AIフィードバックボタンが押せない
原因:
- 表示ボタンIDが retryDailyFeedback なのに、イベント側が generateDailyFeedback を探していた。

修正:
- ボタンIDとイベントを統一。
- 初回生成 / 再分析の両方で同じボタンが動作。
- API未設定時は設定が必要と分かるエラーを返す。
