# WORKNOTE v25

## MTG完全リニューアル
- MTG入力を「タイトル + 大きな自由メモ欄」に簡素化
- 殴り書きメモを保存し、閲覧画面からGeminiで議事録化
- AI議事録: 概要 / 決まったこと / 担当・アクション / 課題 / スタッフ記録候補
- 元メモは常に保持
- AIへの修正指示で議事録だけ再編集
- 選択したアクションだけタスク登録
- 選択したスタッフ記録だけスタッフ履歴へ反映
- MTG一覧で決定件数 / タスク件数 / 未完件数を表示

## メモ画面改善
- 受信箱 → 業務連絡
- 業務連絡は未確認 / 確認済みを管理
- 日報は編集日時ではなく日報日付で並べる
- 新しい日付が上、古い日付が下
- MTGも実施日順
- 通常メモなどは更新日時順を維持
