# WORKNOTE v31.0 — ROLEUP連携・月間成長レポート・バグ修正版

## 今回の主な更新
- 過去の日報が開けない不具合を修正
- 休日モード判定の未定義関数参照を修正
- 日報閲覧画面の未定義変数参照を修正
- メモ一覧・閲覧・編集・削除・「…」メニューのイベント安全化
- メモの太字・色・サイズ・マーカー等の文字装飾機能を撤去
- 通常メモ / 業務連絡 / スタッフメモをシンプルな全文テキスト編集へ変更
- メモを押すとフルスクリーン閲覧
- 日報 / MTGは既存機能維持

## ROLEUP双方向連携
### WORKNOTE → ROLEUP
- AI画面に「ROLEUP訓練」カードを追加
- AIに現在の課題から次のROLEUP課題を選定させる
- 日報フィードバックで実践練習が必要な場合だけ「推奨ROLEUP」を表示
- 「ROLEUPで練習」を押すと課題・重点・商材・難易度をROLEUPへ共有

### ROLEUP → WORKNOTE
- ROLEUPのロープレ結果をWORKNOTEが自動読込
- 総合点 / 6項目 / 改善点 / アドバイス / 会話全文 / 課題IDを参照
- ROLEUP結果を翌日以降の日報AIへ渡す
- AI画面からROLEUP結果をGeminiに再評価させ、次の判断を
  - 再練習
  - 難易度アップ
  - 実務確認
  - 卒業
  に分岐

## 月間成長レポート
AI画面に「月間成長レポート」を追加。
対象月に入力した以下を横断してGeminiが報告書を生成:
- 日報
- 通常メモ / 業務連絡 / スタッフメモ
- MTG
- 日次AIフィードバック
- 週次AIメンター
- 継続記憶 / 店長指示
- 休日の学習 / 訓練
- ROLEUP履歴 / 会話 / 評価

販売実績報告ではなく、副店長としての成長を主題にします。
生成は手動で、保存後は過去月も閲覧できます。
